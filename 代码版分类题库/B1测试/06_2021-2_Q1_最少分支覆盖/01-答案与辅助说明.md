# 2021 S2：findSomething 最少分支测试

正式作答文件：**BranchCompleteTest.java**。原题要求见本目录README或测试文件注释。

正式答案在唯一test方法内，共 **6次方法调用**。题目按findSomething调用次数计数，不按@Test个数。

| a | b | c | expected | 返回表达式路径 |
|---|---|---|---|---|
| -2 | -1 | 0 | true | `||` 左true |
| 1 | -1 | 0 | true | `||` 左false、右true |
| -1 | -2 | 0 | false | `||` 左false、右false |
| 2 | 1 | 0 | false | `&&` 左false |
| 1 | 2 | 0 | true | `&&` 左true、右true |
| 1 | 2 | 1 | false | `&&` 左true、右false |

两个return互斥，各自的短路表达式至少需要3次，所以至少6次；这6次同时覆盖入口 `a<0 || b<0` 的两个子条件真假。已核查12/12个条件结果。

`ExpectedCalculator.java` 只有6行直接调用和打印。修改每行的a、b、c，运行后读取expected即可。分支路径看上面的表，不需要读复杂的输出格式代码。

## 直接运行

在本题文件夹打开终端：

```bash

```

统一脚本把编译产物放在临时目录，不会把.class或XML运行输出混进题目文件夹。若直接编译，请保留本题原package结构和JUnit版本。
