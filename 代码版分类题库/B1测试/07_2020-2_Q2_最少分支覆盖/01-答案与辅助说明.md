# 2020 S2：Person 与 PersonRepository

正式作答文件：**PersonTest.java、PersonRepositoryTest.java**。原题要求见本目录README或测试文件注释。

这道题按**断言实际执行次数**计数；循环执行6次assert也算6例。`&&`、`||` 子条件明确算分支。

### calcInsurancePrice：最少6个价格断言

构造器已经调用calcInsurancePrice，所以new Person后直接通过getter断言结果。

| age | occupation | diabetes | heartDisease | expected |
|---|---|---|---|---|
| 41 | null | true | true | 1100 |
| 41 | 空字符串 | false | false | 360 |
| 41 | policeman | false | true | 500 |
| 41 | policeman | true | false | 400 |
| 40 | policeman | false | false | 200 |
| 41 | teacher | false | false | 350 |

6个互斥价格赋值分支至少各需一次；用这6次顺便覆盖职业的三个短路条件，以及疾病条件真假。其他getter/setter用单独测试覆盖，不额外增加价格断言。

### save：最少2个save断言

新对象id=null：保存并返回同一对象；已有id：抛RuntimeException。成功/抛异常互斥，所以至少2次。正式测试用JUnit4.13支持的assertThrows，不把异常分支写成一个永远不执行的assert。

findById和setSequenceGenerator也各有测试；准备查询数据直接写Map，不额外调用save。static Map每次清理；static序号不假设必定是1。

`ExpectedCalculator.java` 打印6种价格的实际expected，演示首次save、再次save和异常。条件探针核查Person保险18/18、Repository的save 2/2，共20/20。

## 直接运行

在本题文件夹打开终端：

```bash
python3 ../run_all.py --only 07 --helpers
```

也可以在已配置Java依赖的IDE中打开 `ExpectedCalculator.java`，点击main旁的Run。修改main中的参数、普通变量或数组，重跑获取expected，再把**确定的数值/布尔值/异常类型**写回正式测试。辅助类不属于考试提交文件，不要直接多交；正式答案不依赖辅助类计算expected。

统一脚本把编译产物放在临时目录，不会把.class或XML运行输出混进题目文件夹。若直接编译，请保留本题原package结构和JUnit版本。
