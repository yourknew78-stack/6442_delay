# 2019 S2：语句覆盖与分支覆盖

正式作答文件：**MyUtilTest.java、MyStringUtilTest.java**。原题要求见本目录README或测试文件注释。

原PDF第4页明确：**code complete指每条语句至少执行一次**；不是要求每个短路分支都覆盖。

### parseDouble：最少3例（语句覆盖）

`null → 0.0`；`"abc" → 0.0`；`"abc12.34xyz" → 12.34`。

三个不同return路径不能在一次调用中同时走完，所以至少3次。第三例同时走过跳非数字、扫整数、处理小数点、扫小数、转换和正常返回语句。double断言保留delta容差。

### isMixedCase：最少6例（短路分支覆盖）

`null → false`；`"" → false`；`"a" → false`；`"A" → false`；`"aA" → true`；`"Aa0" → true`。

两个早退各需一次；最后 `containsUppercase && containsLowercase` 要3种短路情况；循环内部的提前return true又需一次，合计6。`"Aa0"`的第三轮还没读取0，就发现此前已有大小写并返回true。已核查18/18个条件结果。

`ExpectedCalculator.java` 调用真实两个方法打印expected。运行时注意package是 `utils`，统一脚本已处理。
