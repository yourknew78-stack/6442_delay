# 2023 S1：Riddle 最少分支测试

正式作答文件：**RiddleCheckAnswerTest.java**。原题要求见本目录README或测试文件注释。

`tests()` 内共 **8次checkAnswer调用/8个断言**，每次新建Riddle。

| type | answer | input | expected |
|---|---|---|---|
| TEXT_RIDDLE | Echo | eCHO | true |
| TEXT_RIDDLE | Echo | wrong | false |
| NUMERIC_RIDDLE | 42 | abc | false |
| NUMERIC_RIDDLE | 42 | 42 | true |
| NUMERIC_RIDDLE | 42 | 41 | false |
| ANAGRAM_RIDDLE | Listen | Silent | true |
| ANAGRAM_RIDDLE | Listen | wrong | false |
| null | x | x | false |

下界：文字内部真假2次；数字 `&&` 三种短路情况3次；变位词真假2次；最后类型判断为false需一个不属于三种类型的输入，这个类的构造器允许null类型，且checkAnswer不会因此抛异常，再加1次。合计8；16/16个条件结果均已核查。

`ExpectedCalculator.java` 调用真实checkAnswer，输出输入和返回值。数字错误输入用abc测试正则不匹配，不能用会使parseInt溢出的长数字代替。

为使本文件夹整个综合题可以编译、运行，也补齐了三个Participant状态、GameMaster、Participant的TODO，并按原题要求启用ObserverTest中的两行。原有Participant/Observer测试与新增Riddle测试共9个JUnit方法通过。

## 直接运行

在本题文件夹打开终端：

```bash
python3 ../run_all.py --only 04 --helpers
```

也可以在已配置Java依赖的IDE中打开 `ExpectedCalculator.java`，点击main旁的Run。修改main中的参数、普通变量或数组，重跑获取expected，再把**确定的数值/布尔值/异常类型**写回正式测试。辅助类不属于考试提交文件，不要直接多交；正式答案不依赖辅助类计算expected。

统一脚本把编译产物放在临时目录，不会把.class或XML运行输出混进题目文件夹。若直接编译，请保留本题原package结构和JUnit版本。
