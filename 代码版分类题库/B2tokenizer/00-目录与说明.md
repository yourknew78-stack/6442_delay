## 使用说明

先读各题的 README；2020 S1 的具体要求在 Java 文件注释中。2019 两套题同时附带原始考试 PDF，可查看对应题号的原题。

2020 S2 主要填写 `MyTokenizer.java`，同目录的 `Tokenizer.java` 是配套基类。

2023 S2 保留 `Q1/` 和 `Tests/` 两个并列目录，题目图片和 XML 数据在 `Q1/assets/` 中。

各年份独立练习，不要把不同年份的同名 Java 类放在一起编译。此处仅核对复制完整性，未运行原题测试。
